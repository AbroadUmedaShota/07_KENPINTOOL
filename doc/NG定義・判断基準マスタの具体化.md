# NG定義・判断基準マスタ（完全確定版）

---

## 1. マスタ設計方針（前提ルール）

### 1.1 判断の基本原則

* 判断はすべて **ルール適合／不適合** で行う
* 主観・経験・感覚による判断は禁止
* NG理由は必ず **NGコード** によって付与される
* 自由記述のみでのNG登録は不可

---

### 1.2 NG区分（固定）

| 区分       | 定義   | 業務上の扱い        |
| -------- | ---- | ------------- |
| **NG-A** | 致命不良 | 再スキャン必須（例外不可） |
| **NG-B** | 要対応  | 再処理・差替で回復可能   |
| **NG-C** | 注意   | 目視確認の上で承認可    |
| **OK**   | 問題なし | 次工程へ          |

※ **NG-Aが1件でもあれば案件全体NG**

---

## 2. ページ構造系 NG定義（最優先）

| NGコード  | NG名称    | 判定条件        | 区分   |
| ------ | ------- | ----------- | ---- |
| STR-01S | ページ抜け疑い   | 画像特徴量＋連続性評価で不連続を検知（疑い）  | NG-C |
| STR-01 | ページ抜け（確定）   | 検品者が目視でページ抜けを確定（STR-01Sから昇格）  | NG-A |
| STR-02 | ページ重複   | 同一／高類似ページ検出 | NG-A |
| STR-03S | ページ順序異常疑い | 画像特徴量＋連続性評価で順序違いを検知（疑い）      | NG-C |
| STR-03 | ページ順序異常（確定） | 検品者が目視で順序異常を確定（STR-03Sから昇格）      | NG-A |
| STR-04 | ページ回転誤り | 90°／180°回転  | NG-B |

**補足**

* STR-01／STR-02／STR-03（確定）は一切の例外承認不可（STR-04除く）
* STR-01／STR-03はOCRメタ情報やページ番号取得を前提とせず、画像特徴量＋連続性評価で「疑い（末尾S）」を検知する
* STR-01S／STR-03Sは警告（NG-C）として提示し、検品者が目視で確定できた場合のみNG-Aへ昇格する

## 4. 画質劣化系 NG定義（再スキャン対象明確化）

| NGコード      | NG名称             | 判定条件        | 区分       |
| ---------- | ---------------- | ----------- | -------- |
| QLT-01     | ピンボケ             | エッジ鮮鋭度が閾値未満 | NG-A     |
| QLT-02     | 解像度不足            | 実効DPIが規定未満  | NG-A     |
| QLT-03     | 白飛び／黒潰れ          | 階調分布が極端     | NG-B     |
| QLT-04     | 影・写り込み           | 主要領域に影・物体   | NG-B     |
| **QLT-05** | **線状ノイズ（縦線・横線）** | **直線状欠陥検出** | **NG-A** |

---

### QLT-05（線状ノイズ）詳細定義【重要】

**対象**

* スキャナ機構不具合（ローラー／CIS／ガラス汚れ等）起因
* 用紙端から端まで伸びる縦線・横線
* 複数ページで同位置に再現する線

**判定条件（すべて満たす）**

* 高い直線性
* 一定長以上（ページ高さ・幅の規定割合以上）
* 本文・図面・署名・寸法線を横断

**運用ルール**

* 再処理不可
* 例外承認不可
* 選択肢は **「再スキャン」一択**

## 8. 判断フロー（強制仕様）

1. ツールが **NGコードを自動付与**（疑いコードを含む）
2. STR-01S／STR-03Sは前後比較で目視確認し、確定できた場合のみSTR-01／STR-03へ昇格する
3. 検品者が選択可能なアクション

   * OK
   * 再スキャン
   * 再処理（提案／指示のみ。実行は対象外）
   * 例外承認（NG-B／Cのみ）
4. NGコード未選択では完了不可
5. NG-Aは例外承認・再処理不可

---

## 9. 例外承認ルール（統制）

| 項目   | 内容          |
| ---- | ----------- |
| 対象   | NG-B／NG-Cのみ |
| NG-A | 例外承認不可      |
| 理由   | 定型コード必須     |
| ログ   | 永続保存        |

---

## 10. マスタ管理要件

* NGコードは **固定ID（変更不可）**
* 閾値のみ管理者変更可
* 変更履歴は全保存
* 案件処理中のルール変更禁止

---

## 11. 本マスタで排除される属人化

* 「このくらいならOK」
* 「今回は急ぎだから通す」
* 「前も通したから大丈夫」

→ **すべて不可能**
