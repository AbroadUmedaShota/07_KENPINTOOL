# 検品業務の「今」と「これから」

| 現在の課題 | 本ツールの解決策 |
| :--- | :--- |
| **属人化**：人により判断がバラバラ | **ルール化**：AIが共通基準でチェック |
| **見落とし**：疲労によるミス | **自動検知**：AIが不備を即座に提示 |

# 核心機能：AIと人のハイブリッド

- **AI（ツール）の役割**
  - 大量の画像から「怪しい箇所」を瞬時に見つける
  - 線状ノイズや重複ページを自動指摘
- **人間（検品者）の役割**
  - AIの指摘を最終確認する
  - 「例外」として認めるかの高度な判断を行う

---

# 【最新進捗】技術検証（PoC）完了！

### 全ての「動く仕組み」が揃いました

1. **高速UI**: キーボードだけで数千ページをサクサク判定
2. **PDF対応**: PDFをページごとに自動展開
3. **実用検知**: 線状ノイズ・重複を画像解析で特定
4. **自動保存**: 途中で閉じても続きから再開可能
5. **PDFレポート**: 証跡となる報告書を1クリックで出力

---

# 【機能1】爆速検品：止まらない操作体験

- **マウスを捨てて、キーボードへ**
  - 次ページ、ズーム、OK/NG判定がすべて1キーで完結
- **待ち時間ゼロの表示**
  - 大判の図面や重いPDFも、ページをめくった瞬間に表示
- **「迷い」をなくすUI**
  - 判定中の情報の優先度を整理し、見るべき場所に集中

---

# 【機能2】AIエンジン：プロの目をデジタル化

- **線状ノイズの自動検知**
  - スキャナ汚れ等の縦線・横線をAIが特定。見逃しを防止
- **重複読み込みの防止**
  - 画像の「指紋」を比較。同じページの二重読み込みを警告
- **強制ガード機能**
  - 重大な不備を見逃して「OK」することを物理的に防ぐ

---

# 【機能3】堅牢なデータ保存と再開

- **一枚ごとに、その場で保存**
  - 判定のたびに即保存。アプリを閉じても「続きから」
- **書き込み禁止環境でもOK**
  - 共有フォルダやCD-R上のデータも安全にロード可能
- **「過去の判断」をすべて記録**
  - 誰がいつ何を判断したか、データベースで確実に管理

---

# 【機能4】信頼を届けるアウトプット

- **画像付きPDFレポート**
  - NG箇所の「証拠画像」を自動でまとめた報告書を出力
- **Excel完全対応CSV**
  - Excelで開いても文字化けしない。そのまま集計に利用可能
- **透明性の確保**
  - 判断の根拠が画像付きで残るため、品質の証明が容易に

---

# 【技術スペック】高品質と高速性の根拠

- **表示解像度 (DPI)**
  - **300 DPI** 固定（業界標準の高精細な文字視認性）
- **画像解析エンジン**
  - 世界標準の **OpenCV** を採用。不備をミリ単位で特定
- **判定データ保護**
  - **SQLite** + **ハッシュチェーン**（改ざん不能な監査ログ）
- **動作環境**
  - **Python 3.12 + PySide6** 自己完結型（インストール不要、コピーで動作）
